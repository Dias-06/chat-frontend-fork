▎Чат-приложение

Добро пожаловать в проект чат-приложения, разработанный с использованием современного технологического стека. В этом проекте используются React, Next.js, TypeScript, Tailwind CSS и Zustand для управления состоянием, а также Framer Motion для анимации. Архитектура проекта основана на принципах FSD (Feature-Sliced Design).

Использование Feature-Sliced Design (FSD) обеспечивает масштабируемость и модульность. Это позволяет легко добавлять новые функции без риска сломать существующую логику и упрощает тестирование отдельных компонентов.

▎📦 Технологический стек

• React: Библиотека для построения пользовательских интерфейсов.
• Next.js: Фреймворк для серверного рендеринга и статической генерации приложений на React.
• TypeScript: Язык программирования, добавляющий статическую типизацию к JavaScript.
• Tailwind CSS: Утилитарный CSS-фреймворк для быстрого создания адаптивных интерфейсов.
• Zustand: Простая и легковесная библиотека для управления состоянием приложения.
• Framer Motion: Библиотека для создания анимаций в React.

▎📁 Структура проекта

Проект организован по архитектуре FSD, что позволяет разделить функциональность на независимые модули. Каждый модуль содержит свою логику, стили и компоненты. Основные директории:

src/
├── app/        # Инициализация приложения, layout, providers, роутинг
├── pages/      # Страницы приложения (если используются)
├── widgets/    # Составные UI-блоки
├── features/   # Бизнес-фичи (логин, формы, действия пользователя)
├── entities/   # Сущности предметной области (user, cart и т.д.)
├── shared/     # Переиспользуемые компоненты, утилиты, ui-kit


▎🚀 Установка

Для начала работы с проектом выполните следующие шаги:

1. Клонируйте репозиторий:
   
   git clone https://github.com/akatosphere/chat-frontend-1.git
   
   

2. Установите зависимости:
   
   npm install
   

3. Запустите проект:
   
   npm run dev
   

4. Откройте браузер и перейдите по адресу http://localhost:3000.

## Коммиты

- feat: добавить что-то новое
- fix: исправить баг
- docs: правки в документации
- refactor: переписать код без изменения поведения
- test: добавить/починить тесты
- style: форматирование, точки с запятой
- perf: улучшение производительности
- build: сборка, зависимости, скрипты
- ci: настройка CI/CD
- chore: мелкие задачи, которые никуда больше не попадают

## Как понять, куда класть новый компонент?

3 вопроса:

1. Это примитивная кнопка/инпут/иконка, которая используется везде?
   -> shared/ui

2. Это «объект» из реальной жизни (пользователь, товар, заказ)?
   -> entities/...

3. Это действие пользователя (добавить в корзину, лайк, поиск, вход)?
   -> features/...

4. Это большой блок, который используется на нескольких страницах (шапка, сайдбар)?
   -> widgets/...

5. Это целая страница сайта?
   -> src/app/page-name/page.tsx
